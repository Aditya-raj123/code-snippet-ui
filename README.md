# CodeSnippetUI

A collection of beautiful, reusable UI components and code snippets built with Next.js, React, TypeScript, Tailwind CSS, and Fumadocs.

## Features

- Beautiful reusable UI components
- Copy-ready code snippets
- Next.js and React components
- Tailwind CSS
- Dark mode support
- Documentation powered by Fumadocs
- Ready-to-use components

## 🎨 What is CodeSnippetUI?

**CodeSnippetUI** is a growing library of modern UI components and interactive blocks designed to help developers build beautiful websites without starting everything from scratch.

Instead of spending hours recreating common UI patterns, simply:

```text
🔍 Explore
   ↓
👀 Preview
   ↓
📋 Copy
   ↓
⚡ Paste
   ↓
🚀 Build
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Aditya-raj123/code-snippet-ui.git
```

### 2. Navigate to the project

```bash
cd code-snippet-ui
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

---

## 🏗️ Build for Production

Create a production build:

```bash
npm run build
```

Run the production server:

```bash
npm start
```

## 🎯 Why CodeSnippetUI?

Building a modern interface often means repeatedly creating the same UI patterns.

CodeSnippetUI aims to make that process simpler:

> **Discover → Preview → Copy → Customize → Ship**

Spend less time rebuilding UI and more time creating your product.
